Portal Pengurus & Hak Akses

Khusus Super Admin & Koordinator 8 Cabang Keluarga

Pengunjung umum dapat melihat seluruh silsilah secara terbuka tanpa login. Silakan masuk menggunakan akun pengurus terdaftar untuk menambah, mengedit, atau menyetujui usulan data keluarga.
Terdeteksi Browser Internal Aplikasi (WhatsApp / Medsos)

Google sering memblokir tombol Masuk dengan Google di dalam browser bawaan WhatsApp. Jika gagal, ketuk ikon titik tiga (⋮) atau Kompas/Safari di pojok layar lalu pilih Buka di Chrome / Safari, atau gunakan login Email & Kata Sandi di bawah.

Izin Database Firestore Belum Dibuka (Missing Permissions)

Aplikasi berjalan normal menggunakan data lokal, namun sinkronisasi cloud tertahan aturan keamanan Firebase. Buka Firebase Console → Firestore Database → Rules, tempel aturan berikut, lalu klik Publish: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /artifacts/{appId}/public/data/{document=**} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}
